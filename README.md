# シチュエーションボイス・セリフ生成ツール

Gemini APIを使用して、シチュエーションに応じたボイス・セリフをテキスト生成するWebアプリケーションです。

## 特徴

- **簡単入力 & 詳細入力**: シンプルなテキスト入力から、詳細なキャラクター設定まで対応
- **複数の出力フォーマット**: テキストのみ、シンプル台本、詳細台本、カスタムフォーマット
- **履歴管理**: 生成した内容を自動保存（最大50件ずつ分割保存）
- **お気に入り機能**: 気に入った生成結果を保存してすぐに呼び出し
- **モデル管理**: Gemini APIの複数モデルに対応、お気に入りモデルの登録
- **エクスポート/インポート**: 履歴やお気に入りをJSON形式で保存・読み込み

## セットアップ

### 1. ファイル構成

```
project/
├── index.html          # メインHTMLファイル
├── styles.css          # スタイルシート
├── script.js           # メインJavaScript
├── api.js              # Gemini API連携
├── storage.js          # LocalStorage管理
└── README.md           # このファイル
```

### 2. Gemini APIキーの取得

1. [Google AI Studio](https://makersuite.google.com/app/apikey) にアクセス
2. Googleアカウントでログイン
3. 「Get API Key」をクリックしてAPIキーを取得

### 3. 使い方

1. `index.html` をブラウザで開く
2. 右上の⚙️設定ボタンをクリック
3. 取得したAPIキーを入力して「APIキーを保存」をクリック
4. 設定を閉じて、セリフ生成を開始

## 基本的な使い方

### 簡単入力モード

1. **用途を選択**: ゲームキャラクター、ボイスドラマなど
2. **セリフの長さを設定**: セリフ数、時間、段階から選択
3. **シチュエーションを入力**: 自由にテキストで説明
4. **生成ボタンをクリック**

例:
```
戦闘シーンでの勝利セリフを10個生成
```

### 詳細入力モード

1. **シチュエーション設定**
   - 舞台/場所: 例「学校の屋上」
   - 時間帯: 朝、昼、夕方、夜など
   - 状況説明: 詳しいシチュエーション

2. **キャラクター設定**
   - 名前: キャラクターの名前
   - 性別: 男性/女性/その他/不明
   - 年齢: 例「20」「10代」
   - 性格: 例「明るい」「クール」
   - 口調: 例「です・ます調」「タメ口」
   - 声質: 例「高め」「低め」
   - 役割: 例「主人公」「ヒロイン」

3. **生成ボタンをクリック**

### 出力フォーマット

- **テキストのみ**: セリフだけを出力
- **シンプル台本**: キャラクター名付きの台本形式
- **詳細台本**: ト書き付きの詳細な台本形式
- **カスタムフォーマット**: 独自のテンプレートを設定

カスタムフォーマット変数:
- `{character}`: キャラクター名
- `{line}`: セリフ内容
- `{scene}`: シーン番号
- `{direction}`: ト書き

## 機能詳細

### 履歴から類似内容を避ける

チェックを入れると、過去5件の生成結果を参照し、異なる内容を生成します。

### 再生成

同じ設定で別のバリエーションを生成します。

### お気に入り

生成結果をお気に入りに保存して、後から簡単にアクセスできます。

### エクスポート/インポート

- **履歴のエクスポート**: 生成履歴をJSON形式でダウンロード
- **お気に入りのエクスポート**: お気に入りをJSON形式でダウンロード
- **お気に入りのインポート**: 保存したお気に入りを読み込み

## データ保存について

### LocalStorageの使用

このアプリケーションは、全てのデータをブラウザのLocalStorageに保存します。

**注意事項:**
- APIキーは**平文で保存**されます。共用PCでは注意してください。
- ブラウザのキャッシュをクリアするとデータが消えます。
- 定期的にエクスポート機能でバックアップを取ることを推奨します。

### データ容量

- 履歴は50件ごとに分割保存されます
- LocalStorageの容量制限（約5MB）に注意してください
- 古いデータは定期的に削除することを推奨します

## トラブルシューティング

### エラー: APIキーが設定されていません

→ 設定画面を開き、正しいAPIキーを入力してください。

### エラー: APIキーが無効です

→ APIキーが正しいか確認してください。[Google AI Studio](https://makersuite.google.com/app/apikey)で再確認できます。

### エラー: APIの利用制限に達しました

→ Gemini APIの無料枠には制限があります。時間をおいて再度お試しください。

### セリフが生成されない

1. APIキーが正しく設定されているか確認
2. インターネット接続を確認
3. ブラウザのコンソール（F12）でエラーメッセージを確認

### 生成コンテンツの利用
